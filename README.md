# 🧠 MindBridge: Your Study Universe, Connected.

**MindBridge** is a professional and visually stunning Learning Management System (LMS) that bridges the gap between students and their study materials. Featuring a cinematic web experience and a powerful Flutter mobile app, it's designed to make learning collaborative and engaging.

## 🎬 Cinematic Web Experience
The web frontend has been overhauled with a storytelling splash screen and a premium, responsive design:
- **Story-Driven Splash**: An interactive animation depicting a student's journey from confusion to revelation with the help of MindBridge.
- **Modern Aesthetic**: Glassmorphism, dynamic particle systems, and glowing interactive elements.
- **Mobile First**: Fully responsive layout optimized for all devices, from desktop monitors to mobile screens.

## 📱 Flutter Mobile App
The core of MindBridge is its native mobile application (Android & iOS), providing a buttery-smooth 60fps experience.
- **Smart Notes**: Upload, preview, and share PDFs and images.
- **Study Groups**: Real-time collaboration and discussions.
- **Career Feed**: Stay updated with the latest job and internship opportunities.
- **Native Performance**: Built with Flutter for cross-platform excellence.

## ✨ Key Features
- 🔐 **Secure Auth**: Email/Password and Google Sign-In via Appwrite.
- ☁️ **Cloud Sync**: Seamless data persistence across web and mobile.
- 🌙 **Adaptive Themes**: Smooth transitions between Light and Dark modes.
- 📦 **Releases**: Native APKs available for direct download.

## 🛠️ Tech Stack
- **Frontend**: React (Web) & Flutter (Mobile)
- **Backend**: Appwrite
- **Styling**: Vanilla CSS with cinematic animations
- **State Management**: Provider / React Hooks
